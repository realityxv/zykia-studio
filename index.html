01 / Zyk.ia Studio

Código con control en tus manos

Studio es un espacio móvil especializado en programación. Ayuda a revisar un proyecto, pero tú conservas la decisión sobre cada cambio.

01

Importa tu ZIP

Abre archivos de texto y trabaja sobre una copia local del proyecto.

02

Analiza con tu IA

Configura un proveedor externo. Sus límites, disponibilidad y cobros son responsabilidad del proveedor.

03

Revisa cada cambio

Inspecciona propuestas, elige qué archivos aplicar y conserva la opción de restaurar.

Privacidad y llamadas de IA

Cuando solicitas análisis, los archivos seleccionados se envían al proveedor que configuraste. No pegues secretos ni claves dentro del proyecto.

Flujo Studio

Importa. Analiza. Decide.

La propuesta no se aplica sola: revísala con calma, recházala o aprueba solo los archivos que te sirvan.

1

Selecciona un ZIP

Studio informa si algún archivo queda fuera del análisis.

2

Elige archivos y describe el objetivo

Antes de enviar, revisa el conteo estimado de fragmentos.

3

Inspecciona los hallazgos

Los parches exactos no coincidentes se deben revisar.

4

Aprueba o restaura

Elige archivo por archivo y conserva la versión previa.

5

Exporta a Acode

Descarga y descomprime la copia ZIP actualizada.

01 / Zyk.ia Studio

Code with control in your hands

Studio is a mobile workspace focused on programming. It helps review projects, while you keep the final say on every change.

01

Import a ZIP

Open text files and work on a local copy of your project.

02

Analyze with your AI

Configure an external provider. Its limits, availability and charges are set by that provider.

03

Review every change

Inspect suggestions, choose which files to apply and keep the option to restore.

Privacy and AI requests

When you request an analysis, selected files are sent to your configured provider. Do not put secrets or API keys inside project files.

Studio workflow

Import. Analyze. Decide.

Suggestions are not applied automatically. Review them, reject them, or approve only the files you want.

1

Select a ZIP

Studio tells you if any files are excluded from analysis.

2

Choose files and describe your goal

Review the estimated number of chunks before sending.

3

Inspect findings

Review any exact patches that could not be matched.

4

Approve or restore

Choose files individually and keep a previous version.

5

Export to Acode

Download and unzip the updated project copy.

02 / Documentation

Quick start guide

General instructions for the ZIP distribution. Compatibility can vary by Acode, Android and runtime environment.

01

Extract the complete package

Keep index.html alongside the included vendor, icons and doc folders.

02

Open the folder in Acode

Try the preview. Depending on the source, web features may require HTTPS or localhost.

03

Configure your API

Use your own key; never publish it inside the ZIP or share it in screenshots.

04

Run a small test first

Confirm import and chat first, then test analysis, review and export.

05

Keep a backup

Export and retain the original ZIP before applying changes.

Android background behavior

Android may suspend a WebView page when switching apps. Studio cannot guarantee a request will keep running; return and check the status or error.

Included documentation

The Studio ZIP includes usage, provider and security notes in its doc folder.

AI can be wrong

Review generated code and test it in a safe environment before using it.
